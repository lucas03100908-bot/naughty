# M1 확인 체크리스트

웹캠이 있는 노트북 Chrome에서 `npm run dev -- --port 3100` → http://localhost:3100 → **카메라로 시작하기**. 디버그 패널(D)을 켜 둔다.

## 헤드 트래킹 · 창문 효과
- [ ] 머리를 좌우로 움직이면 스노우볼 옆면이 보인다(물체가 화면 뒤에 '있는' 느낌).
- [ ] 머리를 위아래로 움직이면 바닥 눈과 받침대 윗면이 보였다 가려진다.
- [ ] 화면에 다가가면 물체가 커지고 시야가 넓어진다. 물러나면 반대.
- [ ] 디버그의 x가 내 오른쪽으로 갈 때 +, y가 위로 갈 때 +인지. 반대면 알려 주세요(부호 한 줄 수정).
- [ ] 화면에서 30cm, 60cm일 때 z가 대략 그 값인지. 많이 다르면 `WEBCAM.hfovDeg`를 조정.
- [ ] 가만히 있을 때 화면이 떨리지 않는다. 빠르게 움직일 때 지연이 거슬리지 않는다(`ONE_EURO_POSITION`).
- [ ] 렌더 fps 60 근처, 추적 fps 30 근처.

## 기울이기 (roll)
- [ ] 고개를 오른쪽 어깨로 갸웃하면 roll이 +로, 눈 흐름이 → 로 표시되고 바닥 눈이 오른쪽으로 쏠린다.
- [ ] ±5° 안에서는 흐르지 않는다.
- [ ] 많이 기울일수록 빨리 흐른다.

## 흔들기 (yaw)
- [ ] 좌·우·좌로 도리도리하면 이벤트에 '흔들기 감지'가 뜨고, 바닥 눈이 튀어 올라 휘몰아치다가 약 7초 안에 고르게 다시 쌓인다.
- [ ] 천천히 둘러보기(좌→우 한 번)로는 감지되지 않는다.
- [ ] **축 분리:** 고개만 갸웃할 때 흔들기가 감지되지 않는다. 도리도리할 때 눈이 한쪽으로 흐르지 않는다.
- [ ] 인식이 너무 어렵거나 쉬우면 `SHAKE.minReversals`(3) / `minSwingDeg`(12)를 조정.

## 표정 값 (M3 준비)
- [ ] 찡그리면 browDown이 오른다.
- [ ] 입꼬리를 내리면 mouthFrown이, 눈썹 안쪽을 올리면 browInnerUp이 오른다.

## 카메라 거절 · 마우스
- [ ] 카메라 권한을 거절하면 '카메라 권한이 거절됐어요'가 뜨고 마우스 모드로 바뀐다.
- [ ] 마우스 이동으로 시점, 빠른 좌우 흔들기로 흔들기가 된다.

## 그림 (참조 이미지와 비교)
- [ ] 간판 글자, 문장, 인물 등 IP 요소가 보이지 않는다(가게를 여러 각도에서 확인).
- [ ] 유리가 구로 읽히고, 니트 천과 나무 받침대가 보인다.
