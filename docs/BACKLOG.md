# 백로그

범위 밖 아이디어. 구현하지 않고 적어만 둔다. 마일스톤에 들어갈 때 다시 본다.

## M3 남은 것 (이미 계획된 것)
- 받침대 명판 성적표(지금은 화면 카드), 공유 이미지, 오늘의 순위(Supabase).
- 유리에 비친 얼굴(지금은 옆 카메라 창이 대신한다).

## 룩뎁·배치를 하며 떠오른 것
- **돌 크기:** `ground.glb`의 돌은 미니어처 건물에 비해 크다(건물 높이의 약 1/14, 참조 사진은 1/40쯤). 돌이 더 잘게 만들어진 길 모델이 있으면 바로 바꿀 수 있다(`GROUND.scale`만 맞추면 됨).
- **영상과 3D의 차이:** 전환 영상의 거리(건물 밀도, 간판, 조명)가 우리 3D 거리보다 훨씬 풍성해서, 영상이 끝나는 순간 차이가 느껴진다. 건물 모델을 늘리거나 영상 마지막 장면을 3D 구도에 맞춰 다시 만드는 방법.
- **빛줄기(god rays)와 얕은 심도:** 참조 사진의 하늘 빛줄기, 틸트시프트 느낌.
- **건물 수:** 지금 6채(모델 2종 반복). 참조 사진처럼 촘촘하려면 모델 종류가 더 필요하다.

## M3를 하며 떠오른 것
- **얼굴 AR 장식:** 얼굴 위치에 맞춰 산타 모자·뿔 같은 장식 붙이기.
- **필터 얼굴을 성적표에?** 기획서는 '얼굴 사진은 저장하지 않는다'. 넣으려면 동의 버튼과 기기 안에서만 만드는 공유 이미지로 따로 설계해야 한다.
- **채널 범위 자동 보정:** 평소 표정 2초 동안의 흔들림 크기로 사람마다 `JUDGE.range`를 조정.
- **심사 중 카메라 창이 스노우볼을 일부 가린다.** 좁은 화면에서는 스노우볼을 왼쪽으로 조금 옮기는 방법.

## M2를 하며 떠오른 것
- **근접용 에셋:** 안에서 보면 가게 모델이 거칠고, 마법사 소품(부엉이 조각, 빗자루, 해골+모자 간판)이 보인다. 고해상도 버전을 만들지, IP 요소를 칠해서 지울지, 모델을 새로 만들지 결정이 필요하다.
- **tree.glb 장식:** 마법사 모자, 빗자루, 부엉이, 물약병이 달려 있다. 장난용 트리는 코드로 만든 트리로 바꿨다. 밖에 있는 작은 나무 2그루는 아직 tree.glb다.
- **눈사람·트리 모델링:** 지금은 기본 도형이다. 컴포넌트가 분리돼 있어 교체만 하면 된다.
- **장난 피드백 사운드:** 가로등 딸깍, 눈사람 퍽, 스위치 딸깍. M4 사운드 때.
- **트리 장난 다른 안:** 플러그 뽑기(전선 끌어내기), 입김으로 불어 끄기(입 오므리기 인식), 전구 3개 터뜨리기. 2026-11-18에 별에 눈덩이 던지기로 정했다.
- **들어가기 연출:** 유리를 통과하는 순간 굴절이 한 번 일렁이는 효과.

## M1을 하며 떠오른 것
- **눈송이 크기 다양화:** 지금은 `PointsMaterial`이라 모든 눈송이 크기가 같다. 셰이더로 크기·밝기를 다르게 하면 깊이감이 좋아진다(M4 룩뎁).
- **지붕에 눈 쌓기:** 눈송이가 건물을 통과해 바닥에만 쌓인다. 건물 바운딩 박스로 간단히 막을 수 있다.
- **기울이면 공중의 눈도 쏠리기:** 지금은 공중 눈송이가 roll 방향으로 살짝만 흐른다. 기울기에 따라 중력 방향을 바꾸면 더 그럴듯하다.
- **카메라 보정 화면:** 시작 전에 "화면 중앙을 보고 30cm 앞으로" 같은 보정 단계를 두면 `SCREEN.heightCm`·`WEBCAM.hfovDeg` 개인차를 줄일 수 있다.
- **얕은 심도(DOF):** off-axis 행렬과 함께 쓰려면 초점 거리를 머리 z에서 다시 계산해야 한다. M4.
- **MediaPipe wasm 크기:** 14.7MB(압축 전). 전송은 gzip/brotli로 줄지만 15MB 예산에 영향이 있다. 시작 버튼을 누른 뒤에만 받으므로 첫 화면에는 영향이 없다. M4에서 실제 전송량을 측정한다.
- **유리 반사:** 지금은 생성한 환경광 1개(오른쪽 세로 띠). 참조 이미지처럼 창문 반사를 하나 더 두면 유리가 더 살아난다.
- **니트 천 디테일:** 절차적 텍스처라 가까이서 보면 단순하다. 실제 니트 스캔 텍스처(WebP 1K)로 바꿀 수 있다.
- **가게 세 번째 모델:** 뒤쪽 가게는 `shop_b`를 다시 쓴 것이다. 거리 끝에 다른 형태의 건물이 있으면 반복감이 줄어든다.
