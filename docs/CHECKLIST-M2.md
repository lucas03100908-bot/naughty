# M2 확인 체크리스트

`npm run dev -- --port 3100` → http://localhost:3100 (Chrome, 웹캠). 마우스로도 한 번씩 확인한다.

## 첫 화면 (intro, 밖)
- [ ] 카메라 켜기 / 마우스로 하기 뒤에 '시작하기' 버튼과 조작 안내가 뜬다.
- [ ] 도리도리하면 눈이 흩날린다. 고개를 갸웃해도 눈은 쏠리지 않는다.

## 들어가기 (start)
- [ ] '시작하기'를 누르면 험벅 자막과 함께 전환 영상(6초, 소리 포함)이 3D 스노우볼 위로 겹쳐 들어온다.
- [ ] 영상이 끝나면 끊김 없이 마을 안 3D 거리로 이어지고 타이머가 시작된다.
- [ ] 영상이 멈추거나 안 열려도 몇 초 안에 플레이가 시작된다.

## 마을 안 (play)
- [ ] 거리 한가운데에서 양옆 가게, 휘어 들어가는 돌길, 트리·눈사람이 한눈에 들어온다. 모델끼리 겹쳐 보이는 곳이 없다.
- [ ] 건물·가로등·눈사람 밑에 그림자가 지고, 거리 끝이 밤안개로 흐려진다.
- [ ] 고개를 움직이면 골목이 입체로 보인다. 너무 크게 돌거나 너무 둔하지 않다(`VIEW.insideEyeDepth`).
- [ ] 도리도리해도 눈이 흩날리지 않는다(흔들기는 첫 화면 전용).
- [ ] 고개를 갸웃해도 눈이 쏠리지 않고, 화면도 밀리지 않는다.
- [ ] **눈사람:** 클릭하면 모자 쓴 머리가 굴러 떨어지고 당근 코가 따로 튀어 나간다.
- [ ] **가로등:** 왼쪽 가로등을 클릭하면 깜빡이다 꺼지고, 주변이 어두워진다.
- [ ] **트리 별:** 트리 꼭대기 별이 빛나며 화면 안에 보인다. 클릭하면 눈덩이가 날아가 별을 맞히고, 별이 굴러떨어지며 트리 불빛이 꺼진다.
- [ ] 장난 대상에 마우스를 올리면 손가락 커서가 된다.
- [ ] 위쪽 HUD에 남은 시간, 장난 체크, 점수가 맞게 나온다. 빨리 할수록 점수가 높다.

## 나오기 · 결과 (judge → reward, M3 전 임시)
- [ ] 장난 3개를 다 하거나 60초가 지나면 카메라가 밖으로 물러난다.
- [ ] 결과 카드에 총점과 "눈사람: N초 만에 무너뜨림" 같은 기록이 나온다.
- [ ] '다시 하기'를 누르면 첫 화면으로 돌아가고, 눈사람·가로등·트리가 원래대로 돌아온다.

## 그림
- [ ] 안에서 가게 모델이 얼마나 거칠어 보이는지, IP 느낌(부엉이, 빗자루, 마법사 모자)이 얼마나 강한지 판단한다. 근접용 에셋 결정에 쓴다.
