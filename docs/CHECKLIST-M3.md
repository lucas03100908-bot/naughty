# M3 확인 체크리스트 (심술 심사 + 심술 필터)

`npm run dev -- --port 3100` → http://localhost:3100 → **카메라 켜기**. 디버그 패널(D)의 '심술 심사' 칸을 켜 둔다.

## 흐름
- [ ] 장난이 끝나면 밖으로 물러나고 험벅이 "좋아, 이제 네 심술을 보자."라고 말한다.
- [ ] 오른쪽에 내 카메라 창(거울 반전, 빨간 테두리, 성에, 호랑가시나무 장식)이 뜬다.
- [ ] "평소 얼굴로 가만히 있어 봐." 2초 → "이제 웃으면서 찡그려. 최대한 심술궂게!" 7초 → 결과 카드.

## 점수
- [ ] 무표정으로 있으면 심술도가 거의 0이다.
- [ ] 웃기만 하거나 찡그리기만 하면 심술도가 조금밖에 안 오른다.
- [ ] 웃으면서 눈썹을 내리고 눈을 가늘게 뜨면 심술도가 흰 선(임계값)을 넘어 빨간색이 된다.
- [ ] 입을 크게 벌리면 심술도가 깎인다.
- [ ] 결과 카드에 장난 점수 + 심술 점수 = 총점, 칭호, "심술 미소: 최고 N%, N% 동안 유지"가 나온다.
- [ ] 심사 패널의 미소·찡그림·실눈 막대가 내 표정에 맞게 움직인다. 쉽게 100%에 닿거나 아무리 해도 안 오르면 그 채널의 `JUDGE.range`를 조정.
- [ ] 웃기만 하면 흰 선 바로 아래, 웃으면서 눈썹을 조금 내리면 흰 선을 넘는다.

## 심술 필터
- [ ] 무표정일 때는 거의 원래 얼굴이다(기본 세기 15%).
- [ ] 심술도가 오를수록 입꼬리가 귀 쪽으로 말려 올라가고, 눈썹이 V자가 되고, 눈이 반쯤 감기고, 볼이 올라간다.
- [ ] 고개를 돌리거나 움직여도 필터가 얼굴을 따라가고, 크게 일렁이지 않는다(`FILTER.landmarkSmoothing`).
- [ ] 영상이 접히거나 찢어져 보이는 곳이 없다. 있으면 그 부위의 변형량을 줄이거나 반경을 키운다.
- [ ] 디버그 '필터 고정' 슬라이더로 0~1을 움직여 모양을 확인한다.

## 스노우볼 반응
- [ ] 심술도가 오르면 스노우볼 안에 눈보라가 치고 창문·가로등·전구가 어두워진다.
- [ ] 결과 카드가 뜨면 눈보라가 잦아들고 불이 다시 켜진다.

## 마우스 대체
- [ ] 카메라 없이 하면 카메라 창 대신 '꾹 눌러 심술 부리기' 버튼이 뜨고, 누르는 동안(또는 스페이스) 심술도가 오른다.

## 성적표 · 명판 · 공유 · 순위
- [ ] 결과가 나오면 받침대 정면 황동 명판에 칭호와 총점이 왼쪽부터 새겨진다(가까이 다가가면 읽힌다).
- [ ] 오른쪽 성적표 카드가 명판을 가리지 않는다.
- [ ] '이미지 저장·공유': 스노우볼 사진 + 칭호·총점·기록이 담긴 PNG가 저장되거나 공유 시트가 뜬다. 얼굴은 들어가지 않는다.
- [ ] 닉네임을 넣고 '순위 올리기'를 누르면 오늘의 순위에 들어간다. Supabase 키가 없으면 '이 브라우저'로 표시되고 이 브라우저에만 저장된다.
